# Audit Report - 2026-05-09

This report records the current stable state after the May 9 UI, analytics, and email updates. It is written as a handoff note for Codex, Claude Code, and teammates.

## Executive Summary

- Public homepage, auth pages, and customer-facing pages were moved toward a cleaner Claude Design style: beige background, strong editorial typography, low visual noise, and restrained cards.
- Manager workspace remains on the existing dashboard shell. Public/customer styling is intentionally isolated so manager pages are not redesigned by accident.
- Password reset email was configured and verified locally through Gmail SMTP using a Google App Password.
- Stats page now shows distribution bars for categorical questions and numeric continuous/discrete questions.
- No database schema changes were made in this UI/email documentation batch.

## Analytics

- `feedback/local_service.py` prepares numeric distribution counts for continuous/discrete questions.
- `templates/feedback/stats_overview.html` renders numeric distribution bars below the numeric summary chips when `chart.counts` exists.
- Category charts still use the same bar chart component.
- Pandas/SciPy inference remains Django-fallback only; Flask stats payload is still legacy and does not include the full inference panel.

## Email

Local `.env` requirements for Gmail SMTP:

```env
EMAIL_HOST=smtp.gmail.com
EMAIL_PORT=587
EMAIL_USE_TLS=True
EMAIL_HOST_USER=<gmail-address>
EMAIL_HOST_PASSWORD=<google-app-password>
DEFAULT_FROM_EMAIL=<sender-name-or-email>
```

Important notes:

- Use a Google App Password, not the regular Google account password.
- `.env` must stay untracked.
- Render production must configure the same values in Render environment variables, not in the repository.
